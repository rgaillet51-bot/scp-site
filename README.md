# Fondation SCP — Centre d'Information

Site statique de présentation des anomalies SCP, façon centre d'information de la Fondation SCP.

- Fiches détaillées en français (confinement, description, addendum)
- Images officielles du wiki + visuels « classifiés » pour les objets sans image
- Recherche instantanée et filtres par classe d'objet (Safe / Euclid / Keter)

Contenu adapté du [Wiki SCP](https://scpwiki.com) sous licence [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

## Utilisation

Ouvrir simplement `index.html`, ou servir le dossier :

```bash
python3 -m http.server 8000
```

Aucune dépendance, aucun build.
